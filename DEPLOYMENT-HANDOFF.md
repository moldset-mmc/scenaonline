# Продолжение запуска SCENA

Актуально на 14 сентября 2026 года. Начните с [SCENA_CURRENT.md](SCENA_CURRENT.md): он заменяет прежнюю запись об отсутствии успешного размещения.

Уже существует [публичный предпросмотр](https://scenaonline-qapdlms9m-moldset-8968s-projects.vercel.app/), Vercel сообщает READY. Проект `scenaonline` подключён к GitHub `moldset-mmc/scenaonline`, рабочая ветка Vercel — `main`.

База Turso и два Blob-хранилища созданы на бесплатных условиях и подключены к Production. Полный реестр: [deploy/HOSTING-PROPOSAL.md](deploy/HOSTING-PROPOSAL.md). Они пока не используются кодом приложения. Данные текущего предпросмотра временные, кабинет закрыт.

В чекпойнте подготовлена поддержка восьмизначного временного пароля для предпросмотра. Сам пароль не записан в репозиторий и не установлен этой правкой. Инструкция: [CABINET-ACCESS.md](CABINET-ACCESS.md).

## Продолжение

1. Сверить текущий GitHub SHA, проект Vercel и три существующих подключения. Не создавать их заново.
2. Реализовать и проверить адаптеры базы и файлов с учётом обнаруженных отличий libSQL от sqlite3.
3. Подготовить запуск Production с постоянными данными и закрытым кабинетом до настройки доступа.
4. Настроить пароль приватно, проверить вход и сохранение настроек. Для пробного кабинета можно отдельно опубликовать согласованный preview без рабочих данных.
5. Проверить сохранение базы и фотографий после перезапуска, приватность оригиналов, резервную копию и восстановление.
6. Показать конкретный коммит и состав публикации, выполнить разрешённое размещение и проверить постоянный домен `scenaonline.vercel.app`.

Исторические результаты тестов из старой инструкции не являются проверкой нынешних облачных подключений. Нужны новые результаты при реализации.
