# Продолжение размещения SCENA на Vercel

## Задание владельца

Разместить сайт из `moldset-mmc/scenaonline` на Vercel и дать проверенную живую ссылку. GitHub уже содержит полный локальный пилот V1.7 с дополнительным запуском временного предпросмотра.

## Подготовлено

- `Dockerfile.vercel`: Python 3.12, зависимости из `requirements.txt`, запуск `deploy/start_preview.py`.
- Запуск создаёт новую тестовую базу и копию стартовых медиа в `/tmp`.
- На страницах показывается отметка временного предпросмотра.
- При отсутствии `SCENA_ADMIN_PASSWORD` вход в кабинет закрыт. Публичные страницы доступны.
- Файлы с паролями не входят ни в Git, ни в подготовленный вариант публикации.
- В окружении `VERCEL_ENV=production` этот временный запуск запрещён.
- Новые проверки изоляции запуска: 3 успешны. Проверки основного приложения: 7 успешны. До добавления запуска проверены 247 тестов: 246 успешны, один тест старого архива пропущен.

## Следующий запуск

1. Начать отдельную короткую задачу размещения из этого репозитория, без переноса всей истории проектирования.
2. Проверить текущий коммит `main`, прочитать `DEPLOYMENT.md` и `Dockerfile.vercel`.
3. Создать **preview** проекта `scenaonline` в подтверждённой владельцем команде Vercel. Публиковать только исходники и стартовые медиа; пароли и рабочую базу не передавать.
4. Дождаться сборки. Проверить HTTP и WebSocket, затем «Мою Сцену», Professional, Model, портфолио, запись и Market в браузере телефона.
5. Выдать фактический адрес только после проверки. Указать, что данные этого просмотра временные и вход в кабинет без настройки пароля закрыт.

Для полноценной рабочей версии требуются постоянная облачная база, хранилище пользовательских фотографий и проверка восстановления сессий. Это не заменяется временным предпросмотром.
