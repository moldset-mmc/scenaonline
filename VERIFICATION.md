# SCENA V1.7 — проверка готового комплекта

Дата: 6 сентября 2026. Проверялась финальная версия исходного кода V1.7.

## Автоматические проверки

Команда из папки приложения:

```sh
python -m unittest discover -s tests
```

Результат: **247 теста, 27,876 секунды, OK**. Проверено на Python 3.12, Streamlit 1.63.0, Pillow 12.3.0, qrcode 8.2, cryptography 46.0.5.

Проверки охватывают сохранение и повторное открытие настроек, услуги и записи, заказы магазина с фиксацией цены, переводы и миграции, права FREE/PRO, подпись и повторное применение кодов продления, историю промптов, черновики и публикацию Model, публикации, AI-контекст и поддержку.

Отдельный цикл личной резервной копии и восстановления сохраняет товары, заказы, фотографии, версии промптов, выбранный канал ответа, погашенные коды и историю Model. Публичный экспорт включает опубликованные данные и фотографии товаров; контакты заказчиков, частная переписка, черновики и секреты в него не попадают.

Выбор свободного порта проверен с занятым сокетом. Сгенерированные локальные ссылки следуют фактическому порту запуска; собственный публичный домен сохраняется. Командные файлы Windows проверены по содержимому и Python-составляющим; непосредственный двойной щелчок в Windows в этой среде не выполнялся.

## Настоящий браузер

Основной проход Chromium: **22 проверки без ошибок и горизонтального переполнения**. Проверены публичные страницы и основные разделы кабинета на компьютере и телефоне. Английский интерфейс проверенных экранов не содержит оставшихся русских системных надписей; пользовательский текст переводится через собственные поля RU/RO/EN.

Дополнительные проверки:

- Магазин: каталог → товар → корзина → отдельное подтверждение → сохранённый заказ → кабинет владельца. 12 измерений ширины на 360/390 px без переполнения.
- Model: один основной призыв к приглашению, контурное портфолио, новая визитка, плавная смена кадров; RU/RO/EN.
- Конструктор: создание → оба предпросмотра → публикация → восстановление новым черновиком. На телефонах 360/390 px вложенные предпросмотры также помещаются.
- Публикации: сохранение оформления и английского текста, утверждение предпросмотра, публикация, фактический Story-файл 1080×1920 с ценой и персональной ссылкой в подписи.
- QR: все четыре скачиваемых постера и четыре увеличенных мобильных QR декодируются в ожидаемые адреса. Увеличенный QR визитки Model проверен на 1440/390/360 px. Для сканирования на маленьком экране предусмотрено увеличение нажатием; уменьшенная миниатюра сама по себе не служит гарантией считывания.

Отчёты: `qa/v17-release`, `qa/v17-shop`, `qa/v17-model`, `qa/v17-qr-review`, `qa/v17-publications`.

## Что требует данных владельца

Реальная доставка в Telegram, нейросетевые ответы через API, публикация в Meta и банковские операции не выполнялись. Проверки использовали отдельные тестовые базы и контролируемые ответы адаптеров. Подключения AI и Telegram настраиваются владельцем по `CONNECTIONS.md`; статус сохранённого обращения не выдаётся за подтверждённую внешнюю доставку.

Магазин принимает заказы; способ оплаты и получения согласуется лично. Локальный запуск не размещает сайт в интернете. Для QR, которыми пользуются клиенты на своих телефонах, нужен доступный публичный адрес.

## Сохранность

Исходная комплектная база не изменялась. SHA-256 `scena_master.db`:

`89252ead187311c62903d493b6c4ee64831a888c1148597dc9c936e792c0f1fa`

Обновление создаёт отдельную папку. Недостающие 17 комплектных изображений, значков и шрифтов добавляются из новой версии; файлы пользователя с теми же именами не заменяются. Отдельный тест проверяет обновление старого пилота, четыре QR-постера, визитку Model, сохранение пользовательской фотографии и оба шрифта.

Запуск обновления готовит своё окружение с необходимыми зависимостями. Проверены сохранение допустимого публичного ключа PRO и отказ до переноса данных при неверном ключе или отсутствующей зависимости прямого Python-запуска. Прежняя установка, данные пользователя и личные ключи не заменяются. В комплект не включаются рабочие тестовые базы, токены, закрытый ключ выдачи PRO и исходные личные PDF.
