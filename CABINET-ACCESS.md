# Кабинет SCENA: пароль, смена и восстановление

Адрес кабинета: https://scenaonline.vercel.app/auth/login

Владелец уже сохранил временный пароль в `SCENA_ADMIN_PASSWORD`. Переменная типа Secret подключена к Production и Preview. Значение не хранится в GitHub. Новый сервер поддерживает пароль от восьми символов; для постоянной работы установите длинный уникальный пароль.

## Как войти

Откройте адрес кабинета, введите сохранённый вами пароль и нажмите «Войти». При переходах между разделами вход сохраняется в защищённом cookie на срок до 12 часов. Кнопка «Выйти» удаляет cookie входа. Здесь один кабинет владельца; отдельных аккаунтов посетителей пока нет.

## Как поменять пароль

1. Vercel → проект `scenaonline` → Settings → Environment Variables.
2. Найдите `SCENA_ADMIN_PASSWORD`, откройте меню и выберите Rotate. Введите новый пароль самостоятельно и сохраните его для Production; при необходимости обновите Preview.
3. Deployments → актуальное развёртывание из `main` → Redeploy в Production.
4. Дождитесь Ready, откройте кабинет и войдите новым паролем. Проверьте отказ старому паролю.

Новый запуск записывает действующую версию пароля в постоянную базу. Прежние cookies и пароль предыдущего развёртывания отклоняются при следующей проверке сессии (кеш проверки — до пяти секунд). Данные сайта и фотографии при смене пароля сохраняются. Само сохранение переменной без нового развёртывания не меняет работающий процесс.

## Если пароль потерян

Владелец с доступом к Vercel устанавливает новый пароль по инструкции выше. Старый пароль не нужен. При потере доступа к Vercel сначала восстановите аккаунт Vercel либо обратитесь к уполномоченному администратору команды.

## Восстановление для будущих пользователей

Автоматического восстановления по почте пока нет. Для него потребуются отдельные аккаунты с подтверждённой почтой и подключённый почтовый сервис. Предусмотренный процесс: «Забыли пароль?» → письмо с одноразовой ссылкой ограниченного срока действия → ввод нового пароля → отзыв прежних сессий. Старый пароль не отправляется по почте.

Источники: [Vercel: переменные окружения](https://vercel.com/docs/environment-variables/managing-environment-variables), [OWASP: восстановление пароля](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html).
