# SCENA.LIVE /newcard

Мобильная визитка платформы и подбор простой личной визитки. Публичный адрес:
`https://scena.life/newcard`. Название бренда остаётся **SCENA.LIVE**.

Исходный интерфейс перенесён из отдельного предпросмотра SCENA
(`appgprj_6ab2e302b4e08191af295a4953854895`, исходный commit
`ed47466e01332fc5d71217f351a9fb47f7b21962`).

## Сборка

Node >=22.13, pnpm 11.25.0:

```sh
cd newcard-ui
pnpm install --frozen-lockfile --ignore-scripts
pnpm run typecheck
pnpm run build
```

Сборка создаёт `public/newcard/index.html` и файлы с хешем в имени.
Результат хранится в Git: Python-контейнер публикует его без Node и без
запуска дополнительного сервера. Обработчики в `scena_web/newcard.py`
не подключаются к базе и не используют кабинет MBStudio.

`pnpm-workspace.yaml` сохраняет переопределение `miniflare>sharp` из
существующего lockfile. Для этой статической сборки postinstall-скрипты
зависимостей не нужны; версии пакетов остаются зафиксированными.

После сборки проверка навигации и валидации в DOM (без отправки анкет):

```sh
cd ../tests/js
npm ci --ignore-scripts
node --test newcard.test.cjs
```

Эти тесты не заменяют просмотр сборки в браузере и проверку на телефоне.

## Что доступно

Сцена с анимацией и паузой, четыре шага (вы / фото / оформление / визитка),
живой предпросмотр, одна фотография с настройкой кадра, три оформления,
локальный черновик с фото и прогрессом, PNG и самостоятельная HTML-визитка.
В подборе нет модулей записи, магазина, настройки доменов и аккаунтов.

Готовность приёма заявки проверяется через `/api/intake/status` только после
раскрытия необязательного блока «Обсудить запуск». Отправка требует отдельного
контакта и согласия. Используется существующий обработчик `scena_web/intake.py`.
Конфигурация приёма использует собственные переменные `SCENA_INTAKE_*`.
Если интеграция недоступна или включён `previewOnly`, отправка отключена.
Просмотр и автоматические проверки не требуют отправки реальных анкет.

Самостоятельная копия для проверки без публикации:

```sh
node preview.mjs /absolute/path/SCENA-journey.html
SCENA_PREVIEW_HTML=/absolute/path/SCENA-journey.html node --test ../tests/js/newcard-preview.test.cjs
```

Копия содержит все ресурсы и запрещает сетевые обращения. PNG/HTML-экспорт
работает локально. Подробности и граница проверки: `REVIEW-CARD-JOURNEY.md`.
