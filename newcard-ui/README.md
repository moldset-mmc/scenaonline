# SCENA.LIVE /newcard

Мобильная визитка платформы и анкета в одном стиле. Публичный адрес:
`https://scena.life/newcard`. Название бренда остаётся **SCENA.LIVE**.

Исходный интерфейс перенесён из отдельного предпросмотра SCENA
(`appgprj_6ab2e302b4e08191af295a4953854895`, исходный commit
`ed47466e01332fc5d71217f351a9fb47f7b21962`).

## Сборка

Node >=22.13, pnpm 11.25.0:

```sh
cd newcard-ui
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
```

Сборка создаёт `public/newcard/index.html` и файлы с хешем в имени.
Результат хранится в Git: Python-контейнер публикует его без Node и без
запуска дополнительного сервера. Обработчики в `scena_web/newcard.py`
не подключаются к базе и не используют кабинет MBStudio.

## Что доступно

Сцена, анимация с паузой, пример сайта, все 6 шагов анкеты, выбор фото,
локальный текстовый черновик, возврат между визиткой и анкетой,
пересылка текущей публичной ссылки.

Отправка анкеты **пока отключена**, о чём сообщается на последнем шаге.
Выбранные фото не покидают браузер. Данные MBStudio, его Telegram,
Turso и Blob не используются. Для рабочего приёма анкет нужно отдельно
подключить собственное хранилище и подтверждённого получателя Telegram.
Не включать кнопку отправки без серверной интеграции.

Изображение сцены — художественная визуализация, созданная ИИ; Софи Леру —
вымышленная героиня демонстрационного сайта. Источник изображения страницы:
проверенный снимок sofileroux.scena.life от 21 сентября 2026.
