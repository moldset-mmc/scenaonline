# SCENA.LIVE /newcard

Мобильная визитка платформы и анкета в одном стиле. Публичный адрес:
`https://scena.life/newcard`. Название бренда остаётся **SCENA.LIVE**.

Исходный интерфейс перенесён из отдельного предпросмотра SCENA
(`appgprj_6ab2e302b4e08191af295a4953854895`, исходный commit
`ed47466e01332fc5d71217f351a9fb47f7b21962`).

## Сборка

Node >=22.13, pnpm 11.25.0:

```sh
cd newcard-ui
pnpm install --frozen-lockfile --ignore-scripts
pnpm run typecheck
pnpm run build
```

Сборка создаёт `public/newcard/index.html` и файлы с хешем в имени.
Результат хранится в Git: Python-контейнер публикует его без Node и без
запуска дополнительного сервера. Обработчики в `scena_web/newcard.py`
не подключаются к базе и не используют кабинет MBStudio.

`pnpm-workspace.yaml` сохраняет переопределение `miniflare>sharp` из
существующего lockfile. Для этой статической сборки postinstall-скрипты
зависимостей не нужны; версии пакетов остаются зафиксированными.

После сборки проверка навигации и валидации в DOM (без отправки анкет):

```sh
cd ../tests/js
npm ci --ignore-scripts
node --test newcard.test.cjs
```

Эти тесты не заменяют просмотр сборки в браузере и проверку на телефоне.

## Что доступно

Сцена, анимация с паузой, пример сайта, все 6 шагов анкеты, выбор фото,
локальный текстовый черновик, возврат между визиткой и анкетой,
пересылка текущей публичной ссылки.

Готовность приёма анкеты проверяется через `/api/intake/status`.
Когда серверная интеграция готова, последний шаг отправляет ответы и
выбранные фото через отдельный обработчик `scena_web/intake.py`.
Конфигурация приёма использует собственные переменные `SCENA_INTAKE_*`.
Если интеграция недоступна или включён `previewOnly`, отправка отключена.
Просмотр и автоматические проверки не требуют отправки реальных анкет.
