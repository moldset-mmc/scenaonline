## User experience

1. Name and professional direction (including Model or a custom display label), optional city.
2. One photograph; optional crop/zoom and movement; continue without a photo.
3. Three visual themes, optional short description and one public contact.
4. Finished card: PNG for sharing and self-contained HTML with photo movement and contact side.

The preview is visible throughout. On phones it uses a compact composition and stays near the controls, except while typing or in short viewports. The full card appears at the finish. The public contact is never populated from an earlier private lead/contact record.

The cover retains the existing SCENA stage image. Mobile zoom reaches 1.27 by 43% of a 10-second sequence. It pauses offscreen, in a hidden document, and through the existing pause control; reduced-motion has a static alternative. Personal photo movement has its own pause control and reduced-motion path.

Only the new card draft is persisted, including the normalized photo, crop, theme and valid completed steps. A confirmation precedes clearing it. Storage failures are visible. Photos are normalized to JPEG with a maximum dimension of 1400 pixels; input up to 12 MiB, output below 1.5 MB. Invalid formats/decode failures preserve the previous photo.

## Optional existing intake integration

Creating/downloading a card makes no network submission. The optional “Обсудить запуск” panel checks the existing intake status, asks for a separate private contact and explicit consent, and uses the existing start/upload/send contract. A Model/custom card label maps to the existing `Другое` intake category with the exact display profession in notes. This does not create platform accounts or change role permissions. The fixed existing feature enum is `Визитка и QR`; no QR or booking is promised or generated by this flow.

Downloaded files do not create a public website or reserve an address. The offline review explicitly disables network requests and intake.
