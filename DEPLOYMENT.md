# Размещение SCENA

Проверено 6 сентября 2026 года для исходников SCENA Pilot V1.7.

## Текущее приложение

Точка входа — `scena-master-standalone.py`. Сервер Streamlit использует HTTP и WebSocket. База по умолчанию находится в `scena_master.db`; её путь можно задать переменной `SCENA_DB_PATH`. Загружаемые фотографии и подготовленные публикации сохраняются внутри `media/` в папке приложения.

Кабинет требует `SCENA_ADMIN_PASSWORD` либо одноимённого секрета Streamlit. Секреты, рабочая база и пользовательские медиа не должны попадать в публичный Git. `.gitignore` разрешает только перечисленные стартовые изображения и шрифты.

## Vercel

На дату проверки Vercel поддерживает контейнерные функции и WebSocket-соединения. Однако экземпляры функций масштабируются и завершаются автоматически. Постоянное хранение SQLite-файла и пользовательских фотографий в локальной папке экземпляра не гарантируется.

Для полноценного размещения здесь нужны:

1. Внешняя постоянная база для профиля, услуг, заявок, заказов, лицензий и переписки.
2. Постоянное файловое хранилище для оригиналов, публикаций и восстановлений.
3. Адаптеры существующих операций SQLite и файлов. Одной замены переменной `SCENA_DB_PATH` на URL недостаточно.
4. Проверка сессий, загрузки файлов, переходов в кабинете и восстановления подключения через прокси Vercel.
5. Проверка сохранения данных после остановки экземпляра и нового развёртывания.

Внешняя база и файловое хранилище для SCENA ещё не настроены. `vercel.json` с рабочим размещением не добавлен: простой импорт текущего проекта не завершает эту адаптацию.

## Размещение текущей версии без замены слоя данных

Нужен сервер с постоянным диском, HTTPS и проксированием WebSocket. Папки базы и медиа должны переживать перезапуск и обновление кода. Для пилота используется один экземпляр приложения; при нескольких экземплярах потребуется общий доступ к данным и корректная маршрутизация сессий.

Команда запуска после установки зависимостей и настройки пароля:

```sh
python -m streamlit run scena-master-standalone.py \
  --server.address 0.0.0.0 \
  --server.port 8501 \
  --server.headless true
```

`start_scena.py` и Windows-команды предназначены для компьютера владельца. Для облачного сервера используется неинтерактивный запуск выше. Не отключайте XSRF/CORS как способ обхода проблем прокси.

## Приёмка онлайн-версии

- Открыть «Мою Сцену», Professional, Model и Market на телефоне.
- Войти в кабинет и пройти несколько экранов без повторного запроса пароля.
- Сохранить текст и новую фотографию, затем проверить их после перезапуска сервера.
- Создать тестовую запись и заказ, проверить их в кабинете.
- Проверить резервную копию и восстановление в отдельную папку.
- Указать фактический HTTPS-адрес в настройках QR и проверить сканирование.
- Проверить Telegram и AI отдельно с ключами владельца.
