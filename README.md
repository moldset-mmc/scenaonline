## Как работает опубликованный сайт

`Dockerfile.vercel` использует Python 3.12, `requirements-web.txt`, сборку статических файлов и `deploy/start_web.py`. Tornado отдаёт готовый HTML; облачный интерфейс не запускает Streamlit. Turso хранит данные, Private Blob — оригиналы и служебные файлы, Public Blob — опубликованные изображения. Локальный диск контейнера не является основным хранилищем.

Кабинет: https://mbstudio.scena.life/auth/login . Это **один владелец на установку**. Самостоятельная регистрация множества владельцев, общий биллинг и автоматическое создание новых сайтов не представлены как готовые возможности.

Исходники, стартовые публичные материалы и документация находятся в Git. Рабочая база, заявки, заказы, загруженные владельцем оригиналы и секреты туда не входят. Клонирование репозитория не восстанавливает актуальные данные MBStudio — нужна отдельная личная резервная копия.

## Локальная версия

Streamlit сохранён для автономного запуска. На Windows откройте **START-SCENA.cmd** в полной папке проекта; требуется Python 3.11 или новее.

На macOS/Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python start_scena.py
```

Первый запуск создаёт базу со стартовыми данными пилота. Это не нейтральный установщик другого клиента. Перенос своих данных и резервные копии: [LOCAL-GUIDE.md](LOCAL-GUIDE.md).

## Что входит

Моя Сцена, услуги и график по дням, заявки, Model, магазин с галереями, Telegram-лиды и меню статусов, медиатека и QR, промпты, FREE/PRO и подписанные коды продления. Подключения требуют собственных настроек. Автоматического списания с карты нет; [порядок PRO](PRO-RENEWAL-SETUP.md).

## Проверка изменений

```sh
python -m unittest discover -s tests -q
python tests/native_web_acceptance.py
python tests/seo_http.py
python tests/mbstudio_http.py
```

Команды требуют соответствующих установленных зависимостей; проверки выполняются на изолированных данных. Локальный тест не подтверждает действующее подключение production. Различия запусков: [NATIVE-WEB.md](NATIVE-WEB.md), зависимости облака — `requirements-web.txt`, настольной версии — `requirements.txt`.
