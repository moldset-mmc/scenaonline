# SCENA V1.7 — границы поставки

Локальный самостоятельный продукт для одного владельца: Моя Сцена, Professional, Model и личный Market. Основной сценарий — работа со смартфона после размещения на доступном адресе; локальный запуск предназначен для компьютера владельца.

Работают услуги и группы, календарь, заявки и контакты, магазин с заказами, публикации и экспорт изображений, тематические QR-визитки, редактирование RU/RO/EN, базовая и PRO-библиотека промптов, сценарии Model с историей, 60-дневный PRO Trial и подписанное продление, чат и настройки подключения AI/Telegram.

Пользовательские данные хранятся локально. Обновление создаёт новую установку из прежних данных. Личная резервная копия содержит историю и заказы; публичный пакет содержит только опубликованные данные и фотографии. Публичный пакет — подготовленный формат обмена, не автоматическое подключение к будущей платформе.

Каталог всех участников платформы, автоматический банковский эквайринг, автоматическая SMS-доставка и публикация сайта на домене не входят в этот локальный комплект. Магазин принимает реальные заявки на заказ; оплата и получение согласуются владельцем. Заявка «Стать моделью» сохраняет знакомство для дальнейшего оформления, не создаёт автоматически аккаунт в общем каталоге.

Для живых нейросетевых ответов и доставки в Telegram нужны настройки владельца. Без API в чате работает явно обозначенная локальная помощь. Публикация в Meta требует настройки аккаунта и доступного публичного сайта; Instagram/Facebook экспорт файлов работает локально. TikTok исключён.

Все принятые требования текущего прохода перечислены в V1.7-ACCEPTANCE.md. Реальная проверка и ограничения отражены в VERIFICATION.md.
