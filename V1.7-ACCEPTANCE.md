# SCENA V1.7 — accepted batch and review ledger

Local standalone owner product; public pages and workspace remain one brand. Existing user data must migrate without replacement. The stock database is not edited during development.

## Required paths

- Visitor: My Scene → prominent owner-labelled booking action → service → month/day → two unnamed time groups → review/contact → durable request → personal Scene.
- Model: glamorous intro → five approved looks → one invite action; unobtrusive portfolio; editable identity/story RU/RO/EN. Model navigation toggle hides both entry points.
- New model: platform-owned inclusive beauty/photo/fashion introduction; adult women, beginner-friendly; terms agreed per invitation, no guaranteed jobs/free procedures.
- Owner: Work opens first → requests/services/schedule/shop orders. Large smartphone controls, faint thematic image cards. PRO always reachable; trial reminder below content/quick preview.
- Content: separate names RU/RO/EN; owner-owned professional, booking and course banner copy; platform owns recruitment copy.
- Shop: fourth direction; owner-created products/recommendations, real order review, contact and durable order; no simulated online payments. Expiry retains already published work and fulfillment.
- Promotion: photo-led Instagram exports with selectable neutral frame, visible SCENA, personal post URL in caption; original preserved.
- Prompts: English generation instructions, localized catalog; basic Gloss free, professional tools/versioning PRO, historical versions remain readable after expiry.
- Model builder: safe blocks/presets, drafts/history; explicit desktop+mobile review before publication; expired PRO cannot change structure/effects.
- QR: four themed portraits and four saved prompts, scannable generated QR with small SCENA logo; never hallucinated pixels/domain.
- Help: profile-aware real AI adapter and persistent question/answer wall; local guidance clearly identified; team request has chosen reply channel and actual Telegram correlation. Credentials/operator setup separate; no fake delivery.
- PRO: signed owner-bound renewal code after separately verified payment; tamper/replay/expiry checks; operator private key never distributed.
