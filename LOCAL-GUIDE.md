# SCENA V1.7

Моя Сцена, Professional, Model и Market — личное пространство с услугами, заявками, фотографиями, публикациями и магазином. Данные сохраняются в вашей папке SCENA.

**Уже работали в предыдущей версии? Сначала перенесите свои данные по инструкции ниже.**

## Обновить прежнюю SCENA

1. Закройте окно запуска старой версии. Распакуйте новый архив в отдельную папку.
2. В **новой** папке дважды нажмите **UPGRADE-SCENA.cmd**. При первом запуске дождитесь подготовки окружения; для установки зависимостей нужен интернет.
3. Вставьте полный путь к старой папке SCENA, в которой находятся ваши сохранённые изменения.
4. Проверьте имя владельца и предложенную новую папку. Введите **ДА** для переноса.
5. Откройте созданную папку **SCENA-UPGRADED-V1.7-…** и запустите в ней **START-SCENA.cmd**.

Старая папка сохраняется. Переносятся база, фотографии, тексты, услуги, заявки, публикации и другие сохранённые данные. Подключения AI и Telegram привязаны к отдельной установке: для новой папки настройте их снова. Запуск чистой версии без переноса не подхватывает изменения из старой папки.

## Первый запуск

1. Установите Python 3.11 или новее, если его ещё нет на компьютере.
2. Распакуйте **весь** архив. Откройте **START-SCENA.cmd** двойным щелчком.
3. При первом запуске дождитесь установки зависимостей — для неё нужен интернет.
4. Введите пароль от 8 символов. При вводе символы не отображаются. Этот же пароль используйте при входе в рабочий кабинет.
5. Откройте страницу в появившемся браузере. Если браузер не открылся, скопируйте **только ссылку** из окна запуска в адресную строку браузера.

Оставьте окно запуска открытым, пока работаете. При занятом порте 8501 программа выбирает свободный порт автоматически: используйте адрес, который она напечатала. Ссылки и пояснения не нужно вставлять в PowerShell. Отдельные `.py`-файлы двойным щелчком не запускайте.

## Где что менять

После входа открывается **Работа** — обзор заявок и быстрые действия. Все основные разделы доступны сверху.

| Раздел | Что здесь делать |
|---|---|
| **Работа → Заявки** | Проверять обращения и подтверждать записи. |
| **Работа → Услуги** | Создавать услуги, объединять их в группы, менять описание, цену и длительность. |
| **Работа → График** | Открывать дни и интервалы для записи. |
| **Страницы → Моя Сцена** | Менять имя на RU/RO/EN, личную историю, главное фото, кнопки и видимость направлений. |
| **Страницы → Professional** | Оформлять профессиональную страницу, описания и портфолио. |
| **Страницы → Model** | Оформлять знакомство, образы, подписи, портфолио и модельный сценарий. |
| **Страницы → Market** | Добавлять товары с ценой и личной рекомендацией, оформлять витрину и работать с заказами. |
| **Продвижение → Публикации** | Готовить посты, выбирать оформление и формат, публиковать в своей Сцене. |
| **Продвижение → Промпты** | Выбирать задания для своего AI, создавать и сохранять версии промптов. |
| **Продвижение → QR-коды** | Скачивать QR для записи, Моей Сцены, Professional и Model. |
| **PRO** | Смотреть возможности и срок доступа, подавать заявку и вводить код продления. |
| **Помощь → SCENA Ассистент** | Задавать вопросы и видеть ответы в общей переписке. |
| **Помощь → Команда SCENA** | Написать команде и выбрать, где получить ответ. |
| **Настройки → Подключения** | Настроить AI и Telegram владельца. |
| **Настройки → Резервная копия** | Сохранить или подготовить перенос своих данных и фотографий. |

После изменения нажмите кнопку сохранения в соответствующем блоке. Публичный результат проверяйте через предпросмотр. Для публикации заполните и проверьте нужные языковые версии.

## Market: первый товар и заказ

Откройте **Страницы → Market → Товары**. Добавьте фотографию, название, описание, цену и свою рекомендацию на RU/RO/EN. Проверьте переводы и опубликуйте товар. Название и описание всей подборки меняются во вкладке **Витрина**.

Покупатель добавляет товары в корзину, оставляет контакты и отдельно подтверждает состав и сумму заказа. Заказ появляется у вас во вкладке **Заказы**. Наличие, получение и оплату вы согласовываете лично; автоматического списания денег с карты здесь нет.

## Фотографии и промпты

Установленные изображения находятся в `media/model-slider`, `media/scena-v13` и `media/qr-scenes`. Четыре тематические QR-визитки подготовлены для Марии; соответствующие промпты включены в библиотеку. Новые портреты знакомства сохраняются в `media/model-intro`, портфолио — в `media/portfolio`, фотографии товаров — в `media/shop`. Кадры выбираются и заменяются через соответствующий редактор; прежние сохранённые оригиналы можно выбрать снова.

Используйте JPG, PNG или WebP до 20 МБ. Для крупного показа лучше исходный снимок от 1600 px по длинной стороне; конкретные минимальные требования указаны рядом с загрузкой. Для Model отдельно проверьте кадрирование на компьютере и телефоне.

Промпты находятся в **Продвижение → Промпты**. Скопируйте подготовленный текст в свой AI вместе с оригинальной фотографией, получите изображение и загрузите результат в SCENA. Подробности и правила FREE/PRO — **PROMPT-LIBRARY-GUIDE.md**.

## Подключить AI и личный Telegram

Для нейросетевых ответов нужны **ваш API-ключ, ID модели и адрес Responses API**. Введите их в **Настройки → Подключения** либо запустите **CONNECT-AI.cmd**. Сохранение настроек не отправляет запрос: связь проверяется первым вопросом Ассистенту. Без API работает подписанный локальный помощник **«Подсказки SCENA»**.

Для обращений команды нужны **токен отдельного Telegram-бота и ваш личный chat ID**. Запустите **CONNECT-TELEGRAM.cmd**: программа поможет подтвердить получателя и предложит отдельный тест. Обращение приходит вам в Telegram вместе с выбранным каналом обратной связи. Для ответа внутри SCENA используйте **Reply / Ответить** на сообщение бота; пользователь получает ответ после обновления переписки. Для Telegram, SMS или email вы отвечаете лично по указанному контакту.

Ключи остаются в личных настройках компьютера вне папки сайта. Подробная настройка и проверка — **CONNECTIONS.md** и **TELEGRAM-SETUP.md**. Продление PRO после проверки оплаты владельцем платформы описано в **PRO-RENEWAL-SETUP.md**.

## Ссылка и QR для телефона

`localhost` открывается только на компьютере, где работает SCENA. Для клиентов нужен адрес опубликованного сайта, доступный с их телефона. После размещения укажите его в **Продвижение → QR-коды** и проверьте сканирование. Сам локальный запуск не публикует сайт в интернете.

## Сохранить резервную копию

Откройте **Настройки → Резервная копия** и скачайте личную копию. Она содержит данные и фотографии. Для восстановления запустите **RESTORE-SCENA.cmd** рядом с полной распакованной версией: программа создаст отдельную папку для восстановленного сайта.

Результаты проверок сборки — **VERIFICATION.md**. Данные реальных AI/Telegram-подключений проверяются отдельно на компьютере владельца.
